# Career Match AI

A career recommendation website built with Python and Flask.

## Features
- Career interest selection
- Skills-based career matching
- Skill match percentage
- Matched and missing skills
- Career descriptions

## Technologies
- Python
- Flask
- HTML
- CSS
- Git and GitHub

## Run Locally

1. Install dependencies:

   python -m pip install -r requirements.txt

2. Start the website:

   python app.py

3. Open http://127.0.0.1:5000

## Project Status
Initial prototype using rule-based skill matching.
